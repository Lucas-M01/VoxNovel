# Especificações de referência

Esta pasta preserva o planejamento usado na reconstrução do VoxNovel. Os documentos
propõem uma arquitetura maior que a versão entregue e não são a lista de recursos
implementados nem o guia de instalação atual. Números de versões de stack, serviços
e trechos de código aqui são históricos; os lockfiles e a documentação atual têm
os detalhes usados pelo projeto.

Por exemplo, login/contas, estatísticas, glossário, Redis/ARQ, TTS remoto e vários
pares de tradução aparecem nas propostas, mas não fazem parte da entrega atual.
O trabalho aprovado foi delimitado por paridade com o protótipo e por exceções
expressamente registradas pelo dono.

Para conhecer o projeto que funciona hoje, consulte:

- [README principal](../../README.md): funcionalidades, stack, instalação e uso.
- [ANALISE.md](../ANALISE.md): contrato de escopo e paridade.
- [DECISIONS.md](../DECISIONS.md): decisões aprovadas e mudanças posteriores.
- [WBS_STATUS.md](../WBS_STATUS.md): relação entre cada proposta e o que foi feito.
- [VALIDACAO.md](../VALIDACAO.md): evidências, aceite Android e limites conhecidos.

O histórico permanece no GitHub para contextualizar decisões; não é necessário
implementar o restante das propostas para considerar a versão atual concluída.
