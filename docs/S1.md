Este documento registra um procedimento reproduzível, não um resultado aprovado.

## Abrir o harness privado

Na raiz, com Node e dependências da fundação instalados:

```sh
yarn workspace @voxnovel/mobile speech:harness
```

Abrir o QR apresentado pelo Expo no Android, em Expo Go compatível com SDK 58 ou
em build de desenvolvimento compatível. Usar a mesma rede do computador.
`VOXNOVEL_HARNESS_PORT` permite escolher a porta do servidor de desenvolvimento.
O harness é gerado em `.private/voxnovel-speech-harness`, ignorado pelo git,
com identificador distinto do app. Ele importa os serviços reais, prepara apenas
dois capítulos sintéticos no sandbox dele e não precisa do backend/Supabase.
A interface principal do produto ainda é a fundação, sem leitor completo.

No harness, tocar “Preparar dois capítulos sintéticos” e depois “Iniciar capítulo 1”.
O texto curto serve para conferir controles e avanço automático ao capítulo 2.
Ligar o texto longo e preparar novamente para testes em background/tela bloqueada.
A preparação substitui somente os arquivos sintéticos do próprio harness.

Para conferir os bundles sem aparelho:

```sh
yarn workspace @voxnovel/mobile speech:harness --export
```

Isso verifica empacotamento Hermes; não verifica execução nativa. Nenhum APK foi
instalado por esse comando. Expo Go e um APK próprio têm ambientes diferentes:
registrar qual foi usado e manter a validação do build de distribuição pendente.
